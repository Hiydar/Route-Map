# 🗺️ خارطة طريق وتتبع المشاريع البرمجية (Software Project Roadmap)

نظام تفاعلي لتتبع مراحل بناء وإدارة المشاريع البرمجية خطوة بخطوة، من بداية الفكرة والتخطيط وحتى التسليم النهائي والدعم الفني.

---

## 📌 مراحل المشروع الرئيسية

1. **فكرة المشروع والتخطيط:** تحديد الأهداف، تحليل المتطلبات، ودراسة الجدوى.
2. **التصميم:** تصميم واجهة المستخدم (UI/UX) وهندسة النظام.
3. **التطوير:** كتابة الكود البرمجي للواجهات الأمامية والخلفية.
4. **الاختبار والجودة:** إجراء اختبارات الوحدة، اختبار النظام، وإصلاح الأخطاء.
5. **النشر والتسليم:** إعداد بيئة الإنتاج وإطلاق المشروع.
6. **الصيانة والدعم:** مراقبة الأداء وتحديث النظام بشكل دوري.

---

## 🛠️ التقنيات المستخدمة

- **HTML5 & CSS3:** لتنسيق واجهة المستخدم والتنقل بين المراحل.
- **JavaScript:** للتفاعل وتحديث حالة المرحلة الحالية للمشروع.
- **Python:** لإدارة وتسلسل مراحله برمجياً.

---

## 🚀 كيفية التشغيل

1. قم بفتح ملف `index.html` في أي متصفح.
2. انقر على المرحلة الحالية التي يعمل عليها الفريق لتحديد حالة التقدم تلقائياً.
